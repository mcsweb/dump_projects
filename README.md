**Dump Project Script v4** — мощный PHP-скрипт для генерации Markdown-дампов структуры проекта с веб-интерфейсом на Foundation 6. Создает подробную документацию проекта за секунды!

## ✨ Возможности

- **📁 Полная структура**: Древовидное отображение всех папок и файлов
- **⚡ Два режима работы**: Только структура или полный дамп с содержимым файлов
- **🎯 Умная фильтрация**: Исключение файлов и папок по маскам (wildcards)
- **🕐 Автоматические имена**: Дампы сохраняются с датой и временем
- **🎨 Современный интерфейс**: Веб-форма на Foundation 6 с CDN-подключением
- **🚀 Оптимизированная производительность**: Один рекурсивный проход по файловой системе

## 🛠 Технологии

- PHP 7.0+ (с поддержкой `fnmatch()`)
- Foundation 6 (подключается через CDN)
- Markdown-форматирование
- Полная поддержка UTF-8

## 📦 Использование

1. Загрузите скрипт в корень проекта
2. Откройте в браузере `dump_project.php`
3. Настройте параметры через интуитивную форму
4. Сгенерируйте и скачайте Markdown-дамп

## 🎯 Идеально для

- Документирования проектов
- Отладки и анализа структуры
- Передачи проектов между разработчиками
- Создания снимков состояния проекта

## ⚙️ Особенности v4

- **Веб-интерфейс**: Настройки через форму вместо редактирования кода
- **Маски для исключений**: Поддержка `*`, `?` в именах файлов и папок
- **Оптимизация**: В 2 раза быстрее за счет одного прохода
- **Безопасность**: Экранирование вывода и валидация ввода
